The active song is set by Chataigne (consequence "Set Current Song"). Songs that have already played appear in their configured color. Tip: clicking a song sets it as "now" by hand — handy for testing without Chataigne.
#Song name IndexActive Color
Index = the song's fixed number, and it must match the consequence in your state machine. Reordering does not change it. Set the display order by dragging the handle (⠿). Active switched off = the song is hidden from the live dashboard. Color = text color once the song has played.
